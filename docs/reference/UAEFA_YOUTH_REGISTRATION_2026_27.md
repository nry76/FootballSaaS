# UAE FA youth registration requirements, 2026/27 (as supplied by Fursan Hispania)

Source: club-provided PDF, transcribed by hand. **Not an official UAE FA publication; verify against the current federation rules before relying on it.** The source says the federation or FIFA may request additional documents at any time, and that all documents are private and confidential.

## Club process (page 1 of the source)

1. Review the player's status (five categories below).
2. Gather all required documents: complete, legible, up to date.
3. Accepted formats: PDF, JPG, PNG.
4. Name each file, e.g. `Robert.Passport.pdf`, `Robert BirthCertificate.jpg`.
5. Send all documents in a single email to the club's programmes inbox.
6. Wait for the club to confirm, or to say what is missing or wrong.

Guidance in the source: send information as soon as possible, because **FIFA and federation registration can take 3 to 4 weeks for new registrations**; keep copies of everything submitted.

## Five player categories

`Local Player`, `UAE Child`, `UAE Born`, `Resident > 5 years`, `Resident < 5 years`.
(How a child is placed in a category is not defined in the source. See open questions in MVP_PLAN.md.)

## Documents by category

Holder: **P** player, **M** mother, **F** father, **Club** = form provided by the club.

| Document | Holder | Local Player | UAE Child | UAE Born | Resident > 5 | Resident < 5 |
|---|---|:-:|:-:|:-:|:-:|:-:|
| Emirates ID, front and back | P | yes | yes | yes | yes | yes |
| Passport, copy | P | yes | yes | yes | yes | yes |
| Medical report (mandatory check-up at the assigned clinic) | P | yes | yes | yes | yes | yes |
| Birth certificate, copy | P | - | yes | yes | yes | yes |
| Emirates ID, front and back | M | - | yes | - | - | - |
| Passport, copy | M | - | yes | yes | yes | yes |
| Passport, copy | F | - | yes | yes | yes | yes |
| Family Book, or official document confirming UAE nationality (Khulasat Al Qaid) | family | - | yes | - | - | - |
| Residence visa, valid visa page | P | - | - | yes | yes | yes |
| 5-years proof: visas covering 5 years **plus** school registration history (KHDA) | P | - | - | yes | yes | - |
| Continuation studies certificate, current year | P | - | - | yes | yes | yes |
| Father adoption form (provided by the club) | F, Club | - | - | yes | yes | yes |
| Father work contract **and** work validation (same document) | F | - | - | - | - | yes |
| Rent contract **or** apartment title deed | family | - | - | - | - | yes |

Totals: Local Player 3, UAE Child 8, UAE Born 10, Resident > 5 years 10, Resident < 5 years 11.

Observations used in the design:
* UAE Born and Resident > 5 years have identical lists.
* Some lines are bundles (5-years proof), some are either-or (rent contract or title deed), some need two sides (Emirates ID), and one is a club-supplied form to be signed.
* Documents identify **different people** (player, mother, father), not only the player.
* The list contains no player photo requirement, even though a photo is normally needed for registration.
