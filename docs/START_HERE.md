# Sportal: start here (one page)

Working name **Sportal**. Everything below is a plan. **No code or database has been written.**

## What it is
A website (installs like an app) where a parent does everything alone: enquire, book a trial, accept a place, upload documents, follow the UAE FA registration, see the schedule. Coaches and managers stop answering the same questions.

## The pilot has four parts
1. **Prospects:** enquiry links (Instagram, WhatsApp, website, referral, walk-in), a pipeline, follow-ups, trials with an allowance.
2. **UAE FA registration:** the right document list for each child, instant checks, a person approves, one zip with correctly named files, then the club submits in FA-Net.
3. **Scheduling:** drag-and-drop weekly calendar, coach and venue by period, parents see only what is published.
4. **Status and messages:** everyone sees the same live status; WhatsApp and email updates.

## How a family moves
Enquiry, Trial booked, Trial done, Offer made, Accepted (registration can start), Confirmed (any payment recorded), Registered.

## Ten decisions that shape everything
1. One database for all clubs; each club walled off.
2. Under 18: a parent confirms by email before more than seven basic details are held; documents only after the club offers a place and the parent accepts.
3. Registration rules follow UAE FA's own table (6 categories x 3 player types), kept as data so they can change each season.
4. Medical form: the clinic fills it; we store one signed upload; we never read the medical content.
5. FA-Net passwords are never held by us. Recording FA-Net outcomes in our software is allowed (your answer); assisted upload waits for UAE FA's permission.
6. Coaches submit their own players' lists if given the permission; some clubs use an admin.
7. Everything tunable is a setting: terms, fees, trial allowance, venues, teams fielded.
8. Football first; the foundation allows other sports later (a person is an "athlete" underneath).
9. Online payments, Zoho Books, match day, video, AI photo editing: later.
10. Hosted in Frankfurt; works on phones as a web app; English only.

## Later, on purpose
Online payments and gateway, Zoho Books, match-day tools (kits, match list, medical staff notices), weekend fixtures import, wallet ticket, AI document checks, DOFA and YFL rules.
